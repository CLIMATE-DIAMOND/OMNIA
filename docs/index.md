# OMNIA

Welcome to the official documentation of **OMNIA** (Open-source MuNdus Integrated Assessment Model).

OMNIA is an open-source, global Integrated Assessment Model (IAM) based on the **TIMES** framework. Developed within the Horizon Europe **DIAMOND** project, it is designed to analyse long-term energy transitions, climate mitigation pathways, and technology deployment across 28 world regions.
